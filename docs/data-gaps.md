# V1 数据缺口

更新时间：2026-07-02

## 1. 钠含量全部缺失

当前 6 条第三方公开页面只展示热量、蛋白质、脂肪和碳水，没有展示钠值。

影响：

- 无法计算食盐当量；
- 无法评价一餐占每日食盐参考上限的比例；
- `low_sodium` 模式不能排序。

处理方式：页面显示“待补充”，控钠模式明确拒绝运行。

## 2. 份量信息不完整

- 卤鸡腿有明确的每份重量：65 克。
- 三黑元气饭只有“每份”，没有克重。
- 其余四项按每 100 克展示，但没有门店实际一份的出餐克重。

影响：计算结果代表用户选择的来源口径倍数，不一定等于门店实际一份。

## 3. 尚未完成官方交叉核验

老乡鸡已说明溯源报告 2.0 可通过小程序、堂食和外卖等渠道查看，但 V1 没有绕过登录或抓取小程序接口。

影响：现有营养值全部标为“第三方整理”，不宣称官方准确。

后续应由人工通过合法公开渠道逐条核对，并保留页面或报告位置、核验日期及差异说明。

## 4. 菜单覆盖有限

V1 只有：

- 主食 1 项；
- 主菜 4 项；
- 蔬菜 1 项；
- 汤、饮料和甜品 0 项。

当前可枚举 4 个基础组合，足以验证计算和推荐闭环，但不足以代表真实点餐选择。

## 5. 缺少时空维度

数据没有覆盖：

- 城市或地区；
- 门店；
- 在售起止时间；
- 配方版本；
- 堂食与外卖差异；
- 实际批次和分量波动。

后续数据模型应增加 `region`、`available_from`、`available_to`、`menu_channel` 和 `source_version`。
