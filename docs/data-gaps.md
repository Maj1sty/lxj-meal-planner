# 数据缺口

更新时间：2026-07-02

## 1. 钠含量部分缺失

当前 98 条记录中有 95 条包含钠值，3 条早期 FatSecret 记录仍没有钠值。

影响：

- 一餐只要选中任一缺钠餐品，就无法计算完整钠值与食盐当量；
- 不能把缺失部分当成零后给出偏低结果。

处理方式：页面逐条标记钠值状态，整餐计算继续执行缺失值传播。

## 2. 份量信息不完整

- 卤鸡腿有明确的每份重量：65 克。
- 三黑元气饭只有“每份”，没有克重。
- 其余 18 项按每 100 克展示，但没有门店实际一份的出餐克重。

影响：计算结果代表用户选择的来源口径倍数，不一定等于门店实际一份。

## 3. 尚未完成官方交叉核验

老乡鸡已说明溯源报告 2.0 可通过小程序、堂食和外卖等渠道查看，但 V1 没有绕过登录或抓取小程序接口。

影响：现有营养值全部标为“第三方整理”，不宣称官方准确。

后续应由人工通过合法公开渠道逐条核对，并保留页面或报告位置、核验日期及差异说明。

## 4. 门店实时菜单未完成核验

当前共有 98 条记录，覆盖主食、主菜、蔬菜、汤品、早餐、小吃和饮品。该列表以合肥信达好第坊店作为展示模板，但公开地图页面不提供完整点餐清单，因此不能宣称 98 条均为该店当天在售。

完成门店级核验仍需要该店当日菜单照片、点餐页面导出或小票数据，并记录采集日期和渠道。

## 5. 缺少时空维度

数据没有覆盖：

- 城市或地区；
- 门店；
- 在售起止时间；
- 配方版本；
- 堂食与外卖差异；
- 实际批次和分量波动。

后续数据模型应增加 `region`、`available_from`、`available_to`、`menu_channel` 和 `source_version`。
