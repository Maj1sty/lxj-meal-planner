# 来源索引

## 品牌公开信息

- 老乡鸡官方微博认证账号，《菜品溯源报告 2.0》线上可视化说明：
  <https://www.sina.cn/news/detail/5296041042647572.html>

用途：确认官方提供菜品溯源卡和检验报告查询渠道。该页面不提供本项目可直接批量使用的结构化营养数据。

## 营养数据

- FatSecret 老乡鸡品牌页：
  <https://www.fatsecret.cn/热量营养/老乡鸡>

用途：V1 的 6 条热量及宏量营养演示记录。每条记录在 `src/data/foods.js` 中保留具体详情页。

注意：FatSecret 页面明确提示营养值可能不完整或不准确。批量产品化接入应使用正式 API，并遵守其许可和署名要求。

## 计算依据

- 国家卫生健康委员会，《餐饮食品营养标识指南》：
  <https://www.nhc.gov.cn/sps/c100088/202012/9f71d532e5684a54a63090a75eb737fb/files/1732844456897_92407.pdf>

用途：钠与食盐当量换算。指南采用 1 mg 钠相当于 2.5 mg 食盐。
